\section{O Jogo ISOLA}
\label{sec:game}

\textit{ISOLA} (tamb\'{e}m conhecido como \textit{Isolation} ou \textit{Solitude}) \'{e} um jogo
de estrat\'{e}gia para dois jogadores criado por Bernd Kienitz em 1972~\cite{kienitz1972isola}. O objetivo \'{e}
simples: isolar o pe\~{a}o do advers\'{a}rio de modo a que ele n\~{a}o consiga realizar
nenhum movimento v\'{a}lido no seu turno.

\subsection{Regras do Jogo}
\label{subsec:rules}

O tabuleiro \'{e} uma grelha quadrada (normalmente 6{\texttimes}6). Cada jogador possui
um pe\~{a}o que come\c{c}a em cantos opostos do tabuleiro:

\begin{itemize}
  \item \textbf{Jogador~1} (\texttt{x}) come\c{c}a na posi\c{c}\~{a}o
        (linha~0, coluna~0) --- canto superior esquerdo.
  \item \textbf{Jogador~2} (\texttt{o}) come\c{c}a na posi\c{c}\~{a}o
        (linha~5, coluna~5) --- canto inferior direito.
\end{itemize}

Em cada turno, um jogador executa obrigatoriamente \textbf{duas a\c{c}\~{o}es}:

\begin{enumerate}
  \item \textbf{Mover} o seu pe\~{a}o para uma casa adjacente livre
        (horizontal, vertical ou diagonalmente --- tal como um rei no
        xadrez, mas apenas um passo de cada vez).
  \item \textbf{Remover} qualquer casa vazia do tabuleiro (exceto as casas
        ocupadas pelos pe\~{o}es), marcando-a como permanentemente
        inacess\'{i}vel (\texttt{\#}).
\end{enumerate}

\textbf{N\~{a}o \'{e} permitido} saltar por cima do advers\'{a}rio nem entrar em
casas j\'{a} removidas. Vence o jogador que fizer com que o advers\'{a}rio n\~{a}o
tenha qualquer movimento v\'{a}lido no in\'{i}cio do seu turno.

\section{Objetivos de Aprendizagem}
\label{sec:objectives}

A realiza\c{c}\~{a}o deste trabalho visa consolidar os seguintes objetivos:

\begin{enumerate}
  \item Compreender e dominar a sintaxe de programas Prolog.
  \item Utilizar constru\c{c}\~{o}es b\'{a}sicas: \'{a}tomos, termos compostos, listas,
        operadores e aritm\'{e}tica.
  \item Compreender e controlar o \textit{backtracking}.
  \item Saber utilizar predicados embutidos t\'{i}picos
        (\texttt{findall/3}, \texttt{nth0/3}, \texttt{maplist/3}, etc.).
  \item Implementar um jogo de duas pessoas com informa\c{c}\~{a}o perfeita.
  \item Compreender o princ\'{i}pio \textit{minimax}.
  \item Compreender o algoritmo \textit{alfa-beta}: uma implementa\c{c}\~{a}o
        eficiente do \textit{minimax}.
\end{enumerate}

\section{Introdu\c{c}\~{a}o ao Prolog}
\label{sec:prolog_intro}

Para compreender a implementa\c{c}\~{a}o, \'{e} essencial entender os fundamentos
do Prolog~\cite{bratko2001prolog, sterling1994art}. Ao contr\'{a}rio de linguagens como Java ou Python, o Prolog n\~{a}o
descreve \emph{como} calcular um resultado, mas sim \emph{o que \'{e} verdade}.
O computador trata de descobrir como chegar l\'{a}.

\subsection{Analogia: O Detetive e as Pistas}

Imagine que o Prolog \'{e} um detetive. Voc\^{e} fornece-lhe um conjunto de
\textbf{factos} (pistas conhecidas) e \textbf{regras} (dedu\c{c}\~{o}es l\'{o}gicas),
e depois faz-lhe \textbf{perguntas} (consultas). O detetive procura
sistematicamente todas as combina\c{c}\~{o}es poss\'{i}veis at\'{e} encontrar uma
resposta.

\begin{lstlisting}[language=Prolog,
    caption={Factos e regras b\'{a}sicas em Prolog},
    label={lst:prolog_basics},
    numbers=left,
    basicstyle=\small\ttfamily,
    frame=single]
% Factos: quem gosta de que
gosta(maria, gatos).
gosta(joao, caes).
gosta(maria, caes).

% Regra: duas pessoas tem algo em comum
em_comum(X, Y, Coisa) :-
    gosta(X, Coisa),
    gosta(Y, Coisa),
    X \= Y.

% Consulta: ?- em_comum(maria, joao, Coisa).
% Resposta: Coisa = caes.
\end{lstlisting}

A linha que come\c{c}a com \texttt{:-} l\^{e}-se como ``se'': \texttt{em\_comum(X,\,Y,\,Coisa)}
\'{e} verdade \textbf{se} \texttt{gosta(X,\,Coisa)} \'{e} verdade \textbf{e}
\texttt{gosta(Y,\,Coisa)} \'{e} verdade \textbf{e} \texttt{X} n\~{a}o \'{e} igual a \texttt{Y}.

\subsection{Termos e Unifica\c{c}\~{a}o}

O elemento central do Prolog \'{e} o \textbf{termo}. Existem quatro tipos:

\begin{itemize}
  \item \textbf{\'{A}tomo} --- constante simb\'{o}lica: \texttt{gato}, \texttt{x},
        \texttt{'.'}, \texttt{true}.
  \item \textbf{N\'{u}mero} --- inteiro ou v\'{i}rgula flutuante: \texttt{3}, \texttt{4.5}.
  \item \textbf{Vari\'{a}vel} --- come\c{c}a com mai\'{u}scula ou sublinhado:
        \texttt{X}, \texttt{Jogador}, \texttt{\_}.
  \item \textbf{Termo composto} --- funtor com argumentos:
        \texttt{move(1/2,\,3/4)}, \texttt{[a,b,c]}.
\end{itemize}

\textbf{Unifica\c{c}\~{a}o} \'{e} o mecanismo pelo qual o Prolog associa valores a
vari\'{a}veis. Quando se escreve \texttt{X~=~3}, o Prolog unifica \texttt{X} com
\texttt{3}. A unifica\c{c}\~{a}o s\'{o} tem sucesso se os dois termos tiverem a mesma
estrutura.

\begin{lstlisting}[language=Prolog,
    caption={Exemplos de unifica\c{c}\~{a}o},
    label={lst:unification},
    numbers=left,
    basicstyle=\small\ttfamily,
    frame=single]
?- X = 5.            % X = 5  (sucesso)
?- 2/3 = R/C.        % R = 2, C = 3 (decomposicao de termos)
?- [H|T] = [1,2,3].  % H = 1, T = [2,3] (cabeca e cauda)
?- 2 = 3.            % false (nao unificam)
\end{lstlisting}

\subsection{Backtracking}
\label{subsec:backtracking}

O \textit{backtracking} \'{e} o mecanismo de busca do Prolog.
Quando uma tentativa de satisfazer um objetivo falha, o Prolog
\textbf{recua} automaticamente e tenta a pr\'{o}xima alternativa
dispon\'{i}vel.

\textbf{Analogia}: imagine um labirinto. O Prolog tenta um caminho;
se chegar a um beco sem sa\'{i}da, volta atr\'{a}s (\textit{backtrack}) e
tenta o pr\'{o}ximo corredor, at\'{e} explorar todos os caminhos.

\begin{lstlisting}[language=Prolog,
    caption={Demonstra\c{c}\~{a}o de backtracking},
    label={lst:backtrack},
    numbers=left,
    basicstyle=\small\ttfamily,
    frame=single]
cor(vermelho).
cor(verde).
cor(azul).

% Consulta: ?- cor(X).
% X = vermelho   (primeira solucao)
% X = verde      (apos pedir mais: ";")
% X = azul       (terceira solucao)
% false          (sem mais solucoes)
\end{lstlisting}

O predicado \texttt{findall/3} aproveita o \textit{backtracking} para
recolher \emph{todas} as solu\c{c}\~{o}es numa lista, o que \'{e} amplamente
usado neste projeto:

\begin{lstlisting}[language=Prolog,
    caption={findall recolhe todas as solu\c{c}\~{o}es},
    label={lst:findall_intro},
    numbers=left,
    basicstyle=\small\ttfamily,
    frame=single]
?- findall(X, cor(X), Lista).
% Lista = [vermelho, verde, azul]
\end{lstlisting}

\subsection{Listas em Prolog}

Em Prolog, uma lista \'{e} representada como
\texttt{[Elem1,\,Elem2,\,\ldots]}. A nota\c{c}\~{a}o \texttt{[H|T]} separa
a cabe\c{c}a (\texttt{H}) da cauda (\texttt{T}).

No jogo ISOLA, o tabuleiro \'{e} uma \textbf{lista de listas}: cada
linha do tabuleiro \'{e} uma lista de \'{a}tomos.

\begin{lstlisting}[language=Prolog,
    caption={Tabuleiro 3{\texttimes}3 como lista de listas},
    label={lst:board_list},
    numbers=left,
    basicstyle=\small\ttfamily,
    frame=single]
Tabuleiro = [
  [x, '.', '.'],   % linha 0
  ['.', '.', '.'], % linha 1
  ['.', '.', o]    % linha 2
]
% Simbolos: '.' = livre, x = piao P1,
%           o = piao P2, '#' = removida
\end{lstlisting}
