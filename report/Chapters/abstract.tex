This report documents the implementation of the ISOLA strategy board game
in SWI-Prolog, developed as part of the Artificial Intelligence course.
The game state is represented as a list of lists in Prolog, with predicates
for move generation, move application, and end-game detection.
The computer player's artificial intelligence is based on the alpha-beta
algorithm, an efficient implementation of the minimax principle,
enhanced with heuristic move ordering.
The evaluation function combines mobility and board centrality.
Unit testing comprised 33 tests, all passing.
Experimental benchmarks across varying board sizes and search depths
show that depth 4 is practical on 3$\times$3 boards (136\,ms),
but becomes prohibitive on 6$\times$6 boards (approximately
167\,s for the first move), making depth 2 the recommended
compromise for larger boards.
